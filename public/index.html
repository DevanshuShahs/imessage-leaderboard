How do I get this file?

This only works from a Mac - iMessage history lives in macOS, not on an iPhone directly.

  1. Grant your Terminal access to messages: System Settings → Privacy & Security → Full Disk Access → turn on Terminal → quit and reopen Terminal.
  2. Quit the Messages app completely (⌘Q).
  3. Open Terminal (Applications → Utilities → Terminal).
  4. Run this command to make a safe copy on your Desktop: 
    cp ~/Library/Messages/chat.db ~/Desktop/chat_copy.db
  5. Upload chat_copy.db from your Desktop above.

This copies your file - it never modifies or deletes your real Messages data.

How do I get this file?

On a Mac: open the Contacts app → Edit menu → Select All → File → Export → Export vCard.

On an iPhone: go to icloud.com/contacts in a browser and sign in → select all contacts (⌘A / click one, then Select All) → click the gear icon in the bottom-left corner → Export vCard.
